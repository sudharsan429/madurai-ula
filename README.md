# மதுரை உலா (Madurai Ula) — Cultural & Heritage Explorer 🛕

A rich, interactive web application exploring the ancient cultural heritage, world-famous cuisine, spiritual landmarks, and modern attractions of Madurai, Tamil Nadu.

## ✨ Features

- **Heritage & Spiritual Tourism**: Complete curated directory of historic temples, monuments, museums, and natural getaways across Madurai.
- **Iconic Culinary Scene**: Detailed guide to authentic Madurai cuisine, from Jigarthanda and Kari Dosa to Bun Parotta and traditional filter coffee.
- **Interactive Multi-Category Map**: Interactive map powered by Leaflet and OpenStreetMap with interactive custom markers for Tourism, Restaurants, Cafes, Modern hubs, and Stays.
- **Interactive Search & Filtering**: Real-time filtering by category, area, timings, and search keywords with instant live search dropdown.
- **Light Shiny Golden Yellow Heritage Design**: A radiant, luxury golden theme with glassmorphic headers, smooth micro-interactions, responsive grids, and typography (Fraunces serif & Tamil scripts).
- **Comprehensive Area & Festival Guides**: Curated itineraries for Chithirai Thiruvizha, Jallikattu, Float Festival, and neighborhood explorer.

## 🚀 Getting Started

No build tools or runtime installation required. Simply open `index.html` in any modern web browser or serve via any static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve .
```

Then visit `http://localhost:8000` in your browser.
