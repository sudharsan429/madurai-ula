1. Executive Summary & Architecture

Madurai Ula (மதுரை உலா) is an interactive, mobile-first web platform created to preserve, celebrate, and guide visitors through the multi-millennium cultural heritage, sacred architecture, world-renowned street food, legendary dining messes, artisan cafes, and contemporary urban spaces of Madurai — Tamil Nadu's cultural capital and one of the world's oldest continuously inhabited cities.

1.1 Project Objectives & Core Missions

  • Authentic Local Storytelling: Every temple, palace, monument, and dining institution is documented with historical context, architectural significance, operating hours, exact GPS coordinates, and distance from the central Meenakshi Amman Temple.
  • Zero-Framework Extreme Performance: Engineered entirely in standard HTML5, CSS3, and modern vanilla JavaScript (ES6+). Delivers instantaneous page loads, zero compilation dependencies, and offline-resilient architecture.
  • Light Shiny Golden Yellow Heritage Design: A bespoke visual identity reflecting temple gold leaf, radiant Dravidian morning sunlight, and temple gopuram finials. Utilizes ambient radial gradients, specular hover halos, and glassmorphic headers.
  • Interactive Geospatial Mapping: Native OpenStreetMap and Leaflet integration with interactive category pins, one-touch Google Maps navigation directions, and dynamic embedded mini-maps.

const selectedPlace = PLACES.find(p => p.id === itemID) || PLACES[0];

3. Visual Design System: Light Shiny Golden Theme

The visual theme of Madurai Ula is inspired by the glorious temple traditions of Madurai: the beaten brass lamps (Kuthuvilakku), the gold-plated Kalasam finials of the Meenakshi Amman Temple gopurams, and the radiant warm sunlight bathing the temple city.

Theme Philosophy & Aesthetics
Rather than a flat or garish yellow, the "Light Shiny Golden Yellow" theme utilizes multi-stop specular radial gradients pinned to the viewport. As the user scrolls, the background shimmers gracefully, evoking a polished gold plate with ambient specular highlights.

3.3 Component Elevation & Micro-Animations

  • Cards (.card): Formed with crisp rgba(255, 255, 255, 0.97) backdrops and a subtle 1px golden outline. On hover, the card scales by 1.05 with a multi-layered gold shadow (0 18px 40px -6px rgba(215, 155, 20, 0.46), 0 0 20px rgba(255, 220, 80, 0.4)).
  • Glassmorphic Sticky Header (.site-header): Uses backdrop-filter: blur(14px) with translucent light gold tint rgba(255, 250, 225, 0.95) and subtle bottom gold border.
  • Section Bands (.section.band): Alternating stripes receive a rich warm gradient with inset gold shadows for depth.

5.1 Graceful Fallback Engine (Zero Broken Images)

// In js/main.js & js/places.js:
function handleImageFallback(imgEl, title) {
  imgEl.onerror = null; // Prevent recursion
  imgEl.style.display = 'none';
  const parent = imgEl.parentElement;
  if (parent) {
    const badge = document.createElement('div');
    badge.className = 'img-fallback-badge';
    badge.innerHTML = '<strong>' + title + '</strong>';
    parent.appendChild(badge);
  }
}
